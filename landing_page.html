Powerful Features

Everything you need to analyze and optimize your Android development environment

Project Analyzer

Analyze modules, Gradle configurations, plugins, dependencies, and project metadata in a single view. Inspect Kotlin version, AGP, Gradle version, SDKs, and more.

Clean Build

Scan projects for build folders across all modules and safely delete them to reclaim space. Real-time size computation with batch deletion and safety confirmation.

Workspace Analyzer

Scan multiple workspaces to detect actively used Android SDKs, NDKs, CMake versions, and Gradle wrappers. Automatically protect active versions and highlight what can be safely removed.

Storage Analyzer

View storage consumed by Android SDKs, Gradle caches, IDE caches, Kotlin/Native, and AVDs. Track real-time scan progress with elapsed timers.

Settings

Configure custom toolchain paths and manage privacy options. Automatic path validation with quick-reset options and toggle for analytics.
